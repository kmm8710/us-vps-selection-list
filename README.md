## 选美国VPS前，先想清楚这五件事

**1. 你的访问用户主要在哪里。** 如果访客集中在中国大陆，"美国VPS"之间的差距会被线路放大：走普通国际线路的机房，晚高峰延迟可能跑到 200ms 以上甚至丢包；走双向全程 CN2 GIA 的机房，中国东南沿海访问时延通常能压到 120–180ms，且高峰时段也不容易堵。恒创官方对其洛杉矶机房给出的口径是"标配 CN2 高速网络，中国东南沿海访问时延 120–180ms"，并强调自家 CN2 为双向全程、享高 QoS 级别——这一点在选线路时是值得优先确认的，因为市面上有不少"半程 / 单向 CN2"的产品价格更低但体验打折。

**2. 带宽是按"峰值"还是按"独享"理解。** 不少低价美国VPS写的是"1Gbps 端口"，实际是共享突发；真正独享的 50M、100M 带宽价格完全不同。如果你的业务是视频、下载、跨境站点同步这类吃带宽的场景，看配置时要把"峰值带宽"和"月流量包"分开看，而不是只盯一个数字。

**3. 流量是包月还是计量。** 同样写"100M 带宽"，有的套餐给 2TB/月流量，有的给 3TB/月，超量后的处理方式也不一样——有的限速到 1Mbps，有的直接停机或按量加收。下单前务必看一眼"超量怎么算"。

**4. 是否需要 DDoS 防御。** 做跨境电商、游戏代理、金融类业务的，被扫被攻击几乎是常态。美国机房免费的基础防护通常只到 10G 量级，超出会自动封 IP；如果业务对可用性要求高，要提前看清楚有没有付费高防可加。

**5. 备案与合规。** 美国节点本身不需要 ICP 备案，开通即用，这是相比国内服务器一个明显的便利点；但内容仍须符合中美两地法律法规，不能因为"在海外"就当免死金牌用。

## 几个常被问到的细节

**CN2 和"普通美国VPS"差在哪？** 普通美国VPS走的是国际骨干网，国内访问要绕不少节点，晚高峰容易抖动；CN2 GIA 是中国电信专门建设的优质回国线路，恒创提供的是双向全程 CN2，回国延迟和稳定性都明显更好。代价是价格比纯国际线路贵一些——但对国内访问为主的业务，这笔差价基本是必须的。

**支持哪些付款方式？** 恒创官方公示支持支付宝、PayPal 美元支付、银行在线转账、银行线下转账。对国内用户来说支付宝最方便，对企业用户来说银行转账更便于做账。

**能不能退款？** 云服务器支持 3 天内无理由退款，超过退款期不再支持。首次购买者退款会原路返回支付账户，第二次及以上购买行为的退款会退到账户余额。独立服务器和高防类产品退款政策不同，下单前最好先和客服确认。

**需要备案吗？** 不需要。美国、香港、日本、韩国节点都不要求 ICP 备案，开通即用，这也是海外节点相比国内服务器最大的便利之一。

**能不能加 IP？** 美国独立服务器支持额外附加 IPv4，恒创公布的参考标准是 20 元/个/月（具体以客服实时报价为准）。云服务器默认 1 个 IPv4，需要多 IP 同样需要联系客服。
